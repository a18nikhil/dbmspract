Practical 2

Aim

Create a Database "students" and a table "student_details" inside the database. Insert 10 entries with column names: ID, Name, City, Mobile. Show the complete table using DESC command.

Background Information

In MySQL, the DESC (DESCRIBE) command displays the structure of a table. It shows each column's name, data type, whether NULL values are allowed, key information, default value, and extra properties.

This command helps us understand how a table is designed before working with its data. DESC shows the table structure, not the records stored in the table.

Source Code

CREATE DATABASE students;
USE students;

CREATE TABLE student_details (
    ID INT,
    Name VARCHAR(50),
    City VARCHAR(30),
    Mobile VARCHAR(15)
);
