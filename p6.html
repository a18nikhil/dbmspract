Practical 6

Aim

Create a Database and use SELECT commands: Select (all columns), Select (specific columns), Select (with WHERE clause), Select (with GROUP BY clause), Select (DISTINCT clause), Select (with HAVING clause), Select (with ORDER BY clause).

Background Information

In MySQL, the SELECT command is used to retrieve data from a table. It can display all records or only the records that meet certain conditions.

  • SELECT *: Displays all columns.
  • SELECT specific columns: Displays only the selected columns.
  • WHERE: Filters records using a condition.
  • GROUP BY: Groups records with the same value.
  • DISTINCT: Removes duplicate values from the result.
  • HAVING: Filters grouped results.
  • ORDER BY: Sorts records in ascending or descending order.

CREATE DATABASE college;
USE college;

CREATE TABLE student (
    ID INT,
    Name VARCHAR(50),
    City VARCHAR(30),
