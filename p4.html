Practical 4

Aim

Create a Database "Employee" and a table "Employee_details" inside the database. Insert 10 entries with column names: ID, Name, Country, Salary, Mobile. Use ALTER TABLE command: ADD | DROP | MODIFY | RENAME TO (new tablename).

Background Information

In MySQL, the ALTER TABLE command is used to change the structure of an existing table. It allows us to add or remove columns, change their data types, or rename the table.

The four main operations are:

  • ADD: Adds a new column to a table.
  • DROP: Removes a column from a table.
  • MODIFY: Changes the data type or properties of a column.
  • RENAME TO: Changes the name of a table.

CREATE TABLE Employee_details (
