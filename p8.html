Practical 8

Aim

Create a Database and use GROUP BY clause: Group By single column, Group By multiple columns, Group By with HAVING clause.

Background Information

In MySQL, the GROUP BY clause is used to arrange rows having the same values into groups. It is commonly used with functions such as COUNT(), SUM(), AVG(), MAX(), and MIN() to calculate results for each group.

  • GROUP BY single column: Groups records based on one column.
  • GROUP BY multiple columns: Groups records based on two or more columns.
  • GROUP BY with HAVING: Filters groups based on a condition.

The GROUP BY clause helps us organize and summarize data easily.

CREATE DATABASE college;
USE college;

CREATE TABLE student (
    ID INT,
    Name VARCHAR(50),
    City VARCHAR(30),
