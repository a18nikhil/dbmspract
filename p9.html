Practical 9

Aim

Create a Database and use ORDER BY clause: Order By single column, Order By multiple columns, Order By column number. Use UPDATE command.

Background Information

In MySQL, the ORDER BY clause is used to sort records in ascending or descending order. ASC means ascending order and DESC means descending order.

  • ORDER BY single column: Sorts records using one column.
  • ORDER BY multiple columns: Sorts records using two or more columns in sequence.
  • ORDER BY column number: Sorts records using the position of a column in the SELECT list.
  • UPDATE: Changes existing values in a table. The WHERE clause specifies which records should be changed.

CREATE TABLE student (
