Practical 7

Aim

Create a Database and use SELECT with WHERE clause: WHERE with logical operators, WHERE with comparison operators, WHERE with BETWEEN operator, WHERE with LIKE operator, WHERE with IN operator.

Background Information

In MySQL, the WHERE clause is used with SELECT to display only those records that match a given condition.

  • Logical operators: AND, OR and NOT combine or change conditions.
  • Comparison operators: =, >, <, >=, <= and <> compare values.
  • BETWEEN: Selects values within a range, including both limits.
  • LIKE: Searches for a pattern in text. The % symbol matches any number of characters.
  • IN: Selects values that match any value in a given list.

CREATE TABLE student (
