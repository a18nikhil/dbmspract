Practical 5

Aim

Create a Database "Employee" and a table "Employee_details" inside the database. Insert 10 entries with column names: ID, Name, Country, Salary, Mobile. Use single line and double line comments.

Background Information

In MySQL, comments are used to write notes inside SQL code. Comments help us understand the purpose of a command and make the code easier to read.

MySQL ignores comments while executing SQL statements.

  • Single-line comment: Written using -- . It comments out the rest of that line.
  • Multi-line comment: Written between /* and */. It can cover multiple lines.

Source Code

CREATE DATABASE Employee;
USE Employee;

CREATE TABLE Employee_details (
    ID INT,
    Name VARCHAR(50),
    Country VARCHAR(30),
    Salary INT,
    Mobile VARCHAR(15)
);
