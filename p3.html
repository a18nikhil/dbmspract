Practical 3

Aim

Create a Database "students" and a table "student_details" inside the database. Insert 10 entries (ID, Name, City, Mobile). Use commands: Drop Table, Drop Database, Truncate Table.

Background Information

MySQL stores data in databases and tables. Sometimes we need to remove records, a table, or an entire database. MySQL provides three commands for these tasks:

  • TRUNCATE TABLE removes all records from a table but keeps its structure.
  • DROP TABLE removes the table along with its records and structure.
  • DROP DATABASE removes the entire database, including all its tables.

These commands permanently remove data or database objects, so they should be used carefully.

Source Code

CREATE DATABASE students;
USE students;

CREATE TABLE student_details (
    ID INT,
    Name VARCHAR(50),
    City VARCHAR(30),
    Mobile VARCHAR(15)
);
